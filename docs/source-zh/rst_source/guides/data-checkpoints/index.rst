数据与 Checkpoint
=================

当你需要准备示教数据、转换 checkpoint 格式，或恢复已停止的训练时，使用这些指南。

.. list-table::
   :header-rows: 1
   :widths: 32 68

   * - 指南
     - 内容
   * - :doc:`数据采集 <../data_collection>`
     - 采集并预处理示教数据。
   * - :doc:`Checkpoint 转换 <../convertor>`
     - 在不同格式之间转换 checkpoint。
   * - :doc:`恢复训练 <../resume>`
     - Checkpoint 频率与断点续训。
   * - :doc:`LAMP 数据与 RLPD <../lamp_unified>`
     - 从离线机器人数据训练模型并转换 macro 示范。
   * - :doc:`轨迹播放器 <../trajectory_viewer>`
     - 同步播放真机图像并查看动作、状态和奖励。
