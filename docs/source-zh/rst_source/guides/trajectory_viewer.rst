本地轨迹播放器
==============

在浏览器中播放真机采集图像，同时查看同一帧索引的动作、状态、奖励和回合标志。
你可以选择多个目录、切换轨迹，无需先将数据转换成视频文件。

启动播放器
----------

在仓库根目录中，使用已安装 ``torch``、``numpy`` 和 ``Pillow`` 的 Python 环境。
无需启动 Ray，也不需要 GPU 或前端构建。

.. code-block:: bash

   python toolkits/replay_buffer/web_visualizer.py --root /workspace --port 8765

打开 ``http://127.0.0.1:8765``。``--root`` 指定可浏览的工作区根目录；
省略时使用当前目录。服务只读原始数据，默认监听 ``127.0.0.1``。

如果服务运行在远程机器上，在本机转发端口：

.. code-block:: bash

   ssh -L 8765:127.0.0.1:8765 user@robot-host

保持远程服务运行，然后打开同一个本地地址。也可以通过编辑器转发 ``8765`` 端口。
按 ``Ctrl+C`` 停止服务。``--host`` 可修改监听地址；播放器没有登录验证，
远程访问请使用 localhost 和端口转发。

选择数据
--------

1. 在左侧浏览目录，或输入绝对路径、相对于 ``--root`` 的路径，点击「打开」。
2. 对每个需要的目录点击「添加此目录」。
3. 点击「扫描轨迹」，递归列出 ``trajectory_*.pt`` 文件。重叠目录会自动去重。
   可以按文件名或目录筛选。
4. 点击轨迹进行加载。重新扫描即可发现新保存的文件。

扫描只列举文件，不会加载所有张量。播放器仅缓存当前轨迹，现代 PyTorch 存档使用内存映射。
一次扫描最多返回 10,000 个文件；达到上限时，请缩小所选目录范围。
不允许访问 ``--root`` 外的路径或符号链接目标。递归扫描不跟随目录符号链接；
请直接打开目标目录。

查看轨迹
--------

.. list-table::
   :header-rows: 1
   :widths: 28 72

   * - 控件
     - 行为
   * - 播放 / 暂停
     - 按空格或点击播放按钮。勾选「循环」可重复播放。
   * - 时间轴 / 方向键
     - 拖动时间轴，或按左右方向键逐帧查看。帧索引从零开始。
   * - FPS / 倍速
     - 设置采集频率与播放倍速。默认 10 FPS。
       时间显示由 FPS 换算，并非记录中的真实时间戳。
   * - 图像来源 / Batch
     - 切换 ``curr_obs``、``next_obs`` 的相机画面，或选择 batch。
       图像和数值始终使用同一个 transition 索引。
   * - 当前帧数据
     - 按名称筛选非图像字段。向量显示元素索引；浮点数显示到小数点后六位。
       同时显示原始张量形状和 dtype。
   * - 数据曲线
     - 选择数值字段及其维度，点击曲线跳转。长轨迹最多采样 4,000 个曲线点。

所有相机图像解码完成后，浏览器才一起更新画面和数值。连接较慢或图像较大时，
实际播放 FPS 可能降低；播放器不会主动跳帧。相机画面使用原始分辨率的无损 PNG，
逐像素保留记录中的 uint8 图像，不做 JPEG 压缩或缩略图降采样。选择「原始尺寸 · 1:1」
可按原始尺寸查看，超出面板时滚动浏览；「适应窗口 · 无损」将同一张全分辨率图像
适配到面板中。相机标签显示原始分辨率。浮点图像仍会转换为 uint8 后显示。
原始数据保持不变。图像历史或多视角轴会展开为独立画面。
元数据区域显示静态字段及张量形状。

支持的数据
----------

使用 RLinf ``TrajectoryReplayBuffer`` 保存的张量字典：``actions`` 的形状为
``[T, B, ...]``，或不带 batch 的 ``[T, A]``；观测中包含 RGB 图像张量，
例如 ``curr_obs/main_images``、``curr_obs/extra_view_images``。
支持 HWC、CHW 排列，以及 [0, 255] 的 ``uint8`` 或 [0, 1] 的浮点图像。
额外的相机轴会显示为多个视角。长度为 ``T`` 或 ``T+1`` 的非图像张量按帧切片，
匹配的 batch 轴也会按所选 batch 切片。

播放器不要求存在 ``metadata.json`` 或 ``trajectory_index.json``，
使用 ``torch.load(weights_only=True)``，不会回退到无限制的 pickle 加载。
暂不支持 ``.pkl``、LeRobot、HDF5 或任意模型 checkpoint。
没有相机字段时仍可查看数值；无法读取的轨迹会显示错误，你可以继续选择其他文件。
单帧张量超过 1,024 个元素时，显示形状、前 1,024 个值和截断标志。

记录格式见 :doc:`../concepts/replay_buffer`，采集流程见 :doc:`data_collection`。
